# לאן תתקדם התגובה? — Reaction Quotient Q

Standalone, offline-capable Hebrew interactive teaching activity for General Chemistry 2545, Oranim.

## GitHub Pages
1. Extract this ZIP.
2. Upload `index.html` and `README.md` to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
4. The activity opens from your GitHub Pages site and requires no installation.

## Teaching notes
- Four progressive levels: A ⇌ B; 2NOCl ⇌ 2NO + Cl2; COCl2 ⇌ CO + Cl2; and a simplified separated-pure-liquid esterification model.
- Temperature is fixed and cannot be changed.
- Values of K are illustrative teaching values, not assertions of experimental values at a particular temperature.
- Student must select a net reaction direction before running.
- Concentration curves show illustrative relaxation toward mass-balanced equilibrium, not measured reaction rates or kinetic time scales.
- Equilibrium is dynamic even after concentrations stabilize.
- Q is introduced after initial correct investigation.
- Reset clears activity state.
